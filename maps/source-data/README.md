# Original QGIS experiment inputs

These Natural Earth shapefiles, relief archive, experimental `cities.csv`, and
`places.gpkg` are preserved for the original `ancient-greece-map.qgz` project.
They are **not the current atlas place authority**.

For city edits, use **`maps/atlas/data/places.csv`** and follow
[the atlas documentation](../atlas/README.md). The browser loads that master
dataset programmatically; adding or changing a city requires no QGIS edit.
